# David Castillo De Haro — Portfolio

Portfolio personal creado con React, Vite, GSAP y ScrollTrigger.

## Requisitos
- Node.js 18+ recomendado
- npm

## Instalar y ejecutar

```bash
npm install
npm run dev
```

Después abre la dirección local que muestre Vite.

## Producción

```bash
npm run build
npm run preview
```

## Personalización

- Foto: `public/fotoPerfil.jpeg`
- Datos y textos: `src/main.jsx`
- Diseño y colores: `src/styles.css`
- LinkedIn: busca `AÑADE TU URL` en `src/main.jsx` y sustituye el `href="#"` por tu URL.

## Tecnologías
- React
- Vite
- GSAP
- ScrollTrigger
- HTML/CSS/JavaScript

La web está diseñada para funcionar en escritorio, tablet y móvil.
